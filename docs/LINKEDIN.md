# Rascunho

Do curso para a prática: comecei um projeto pequeno em Python para resolver um problema comum, esquecer alimentos na despensa até passarem da validade.

O projeto se chama Prazo. Ele permite cadastrar alimentos, acompanhar o que vence primeiro, registrar consumo ou descarte e exportar os dados em CSV.

A base é Python com Flask e SQLite, com uma interface simples e responsiva. Foi uma oportunidade de aplicar funções, condições, listas e dicionários, além de explorar persistência e testes automatizados, com apoio de IA no desenvolvimento.

É um projeto de estudo, e a ideia agora é entender cada parte e continuar evoluindo.

Repositório: https://github.com/cauamor-dev/prazo
